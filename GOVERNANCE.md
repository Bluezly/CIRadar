# Governance

CI Radar is developed in the open. Technical decisions prioritize security, deterministic evidence, tenant isolation, privacy, interoperability, and reproducible builds.

Maintainers review changes to authentication, storage, cryptography, webhook verification, automated actions, licensing, and data retention with additional scrutiny. Breaking API or schema changes require release notes and a migration path.

No hosted commercial edition is required to unlock features. Organizations may self-host the complete product without feature gates.
